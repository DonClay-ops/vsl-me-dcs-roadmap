# VSL Middle East – Document Control System Roadmap

An animated HTML presentation prepared by Business Experts MEA (BEMEA) for VSL Middle East management. It sets out a phased roadmap for replacing the current document control system with SharePoint Online, Power Apps and Microsoft 365 Copilot.

## Viewing

Open `index.html` in any modern browser. Everything, including the images, is embedded in that one file.

- **→ / Space**: next slide
- **←**: previous slide
- **O**: slide overview
- **F**: full screen

## Disclaimer

Screens, mock-ups, animations and figures are illustrative and use sample data. The actual UI and visuals of the delivered solution and Microsoft products may differ.
